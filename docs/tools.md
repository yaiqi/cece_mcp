# 工具目录

以运行中服务的 `tools/list` 为最终准则。以下为当前工具目录。

| 服务 | 消歧工具 | 查询能力 |
| --- | --- | --- |
| company-mcp | `resolve_company` | 司法/经营风险、工商、知识产权、图谱、评分、舆情、资质、财务、经营明细、企业搜索、融资、授信与投资 |
| group-mcp | `resolve_group` | 集团详情、分类统计、成员企业、融资/资质/产业图谱、风险与机会事件 |
| industry-mcp | `resolve_industry` | 产业评分、评分对比、集中度、企业画像、财务趋势、企业财务、创新能力 |
| park-mcp | `resolve_park` | 园区详情、子园区、产业分布、企业数量与特征、园区企业列表 |
| person-mcp | `resolve_person` | 人物详情、法定代表、任职、受益所有人、实控企业、所属集团、关联企业、伙伴、持股企业 |
| region-mcp | `resolve_region` | 区域评分、企业/专利/产业统计、融资、企业搜索、园区列表/分布/统计、开发区列表、宏观指标 |

园区职责按查询主体划分：明确某一个园区时使用 `park-mcp`；按省、市、区及 `region_code` 查询园区集合、分布和统计时使用 `region-mcp`。
