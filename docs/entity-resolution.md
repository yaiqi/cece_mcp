# 实体消歧与状态协议

每个实体服务都暴露一个独立消歧工具：`resolve_company`、`resolve_group`、`resolve_industry`、`resolve_park`、`resolve_person`、`resolve_region`。

## 调用规则

1. 先调用对应 `resolve_*`；不得由 Agent 猜测 ID、补全名称或自动选择候选。
2. “唯一匹配”时，原样传递 `标准实体` 给查询工具。
3. “多候选”时，展示最多 5 个候选并等待用户选择。
4. 查询工具返回“实体未匹配”时，才可用原始输入消歧后重试一次。
5. “查询无数据”“调用失败”“无权限”不得触发消歧重试。

## 状态码

| 场景 | 状态码 |
| --- | --- |
| 唯一消歧结果 | `唯一匹配` |
| 候选不唯一 | `多候选` |
| 未找到实体 | `未匹配` |
| 后端未识别主体 | `实体未匹配` |
| 查询有结果 | `查询成功` |
| 查询无记录 | `查询无数据` |
| 上游或依赖异常 | `调用失败` |

Milvus 的相似度 `score` 仅用于内部判断；园区消歧的对外候选不返回该字段。
