# cece-mcp-ventureCapitalAndFinancing MCP-server（创投融资服务）

## Tool 1：search_financing_companies

**功能描述**：获取近期早期获投企业列表，支持融资时间/产业/区域/融资轮次/融资金额多维筛选。出参已按需求补全获投企业的实控人、法人、注册资本、成立年限、所属省/市/区、企业简介、官网。

### 输入参数

| 参数名称 | 参数中文名称 | 数据类型 | 是否必填 | 说明 |
|----------|-------------|---------|---------|------|
| start_date | 开始日期 | str | 否 | 融资开始日期，格式 yyyy-MM-dd（如 2026-08-10），不传默认最近 7 天 |
| end_date | 结束日期 | str | 否 | 融资结束日期，格式 yyyy-MM-dd，不传默认今天 |
| industry | 产业名称 | str | 否 | 产业名称（如"人工智能"），内部解析为产业代码后筛选，不筛选传空字符串 |
| region | 区域名称 | str | 否 | 区域名称（如"江苏省"），不筛选传空字符串 |
| finance_rounds | 融资轮次 | list[str] | 否 | 融资轮次筛选，如 ["种子轮", "天使轮", "Pre-A轮", "A轮", "A+轮"]，不筛选不传 |
| amount_min | 金额下限 | float | 否 | 融资金额区间下限（单位：万元），仅传该值代表筛选金额 >= 该值的企业 |
| amount_max | 金额上限 | float | 否 | 融资金额区间上限（单位：万元），仅传该值代表筛选金额 <= 该值的企业 |
| page | 页码 | int | 否 | 页码，默认 1 |
| page_size | 每页条数 | int | 否 | 每页条数，默认 20 |

### 输出参数

| 参数中文名称 | 数据类型 | 说明 |
|-------------|---------|------|
| 状态码 | str | 查询成功 / 查询无数据 / 参数不合法 / 调用失败 |
| 摘要 | str | 结果摘要文字 |
| 总数 | int | 数据总量（如有） |
| 列表 | list[dict] | 早期获投企业事件列表，每个元素包含： |
| ├ 融资方 | list[str] | 融资方名称列表 |
| ├ 投资方 | list[str] | 投资方名称列表 |
| ├ 融资轮次 | str | 融资轮次名称 |
| ├ 融资金额（万元） | float | 融资金额（万元人民币） |
| ├ 融资日期 | str | 融资事件日期 |
| ├ 投资持股比例 | str | 投资方持股比例 |
| ├ 所属省 | str | 企业所属省份 |
| ├ 所属市 | str | 企业所属城市 |
| ├ 所属区 | str | 企业所属区县 |
| ├ 法人 | str | 法定代表人 |
| ├ 注册资本 | str | 注册资本 |
| ├ 成立日期 | str | 企业成立日期 |
| ├ 成立年限 | str | 企业成立年限 |
| ├ 企业简介 | str | 企业简介 |
| ├ 官网 | str | 企业官网 |
| ├ 实控人 | str | 实际控制人 |
